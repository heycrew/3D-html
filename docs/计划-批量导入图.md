# 批量导入图 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在工作台书页版块加一个「批量导入（选文件夹）」按钮：选一个目录后，
按目录树把封面 / 封底 / 每张内容页的本页图与 360 素材一次性灌进书页。

**Architecture:** 分三层。**识别层** `SD.DirImport.scan(entries)` 是纯函数（输入文件路径表，
输出「这本书长什么样」），不碰 DOM / 不碰 `SD.STATE` / 不发请求 —— 这样能在探针里喂假数据
断言；**编排层**在工作台侧（`08-app.js`），负责选目录、弹识别结果预览、串行上传、
最后一次性重建 `STATE.book`；**素材层**复用现有的 `SD.Materials.importFiles`
（它已经做了串行上传 + 降采样 + `POST /@upload`），只补两件小事：提出公用排序器、
按原文件类型决定预览图格式。

**Tech Stack:** 纯 ES5 浏览器 JS。源码 `build/js/*.js` 由 `build/build.py` 按 `JS_ORDER`
拼接进 `build/shell.html` → `studio.html`。测试是 Python + Playwright 探针。

**设计文档:** `docs/批量导入图-设计.md`（§1-§11 是本计划；§12 是另一份计划的主题）
**姊妹计划:** `docs/计划-产物加载性能.md`（建议先做 —— 它让长图录能打开，本计划才谈得上用）

## Global Constraints

- **ES5**：不能出现 `let` / `const` / 箭头函数 / 模板字符串 / `async`/`await`。
  工作台代码同样按文件现有风格写。
- 源码是拼进一个 HTML 的，**模块间只能通过 `SD.*` 通信**；不要用 `import`/`export`。
- 每次改完必须 `python build/build.py` 通过（它逐模块跑 `node --check`）。
- 探针放 `build/.verify/`（已 gitignore，**不提交**）。要有真图夹具。
- 提交信息中文，标题 + 多条 `-m`。
- **不要改** `docs/readme.txt`。
- 后端接口（`desktop/main.js` 与 `serve.ps1` 都实现了）：
  `POST /@upload`（body 是图片二进制，文件名走 `X-File-Name` 头）→ 返回
  `{ url: '/@mat/<seq>/<name>', size }`；`GET /@ping` → `{ ok, boot }`。

## 已确认的规则（来自 design §2.2，不要自行更改）

| 决策点 | 结论 |
|---|---|
| 识别规则 | 子文件夹名**必须纯数字**；非数字目录忽略并列出；页码缺口**保留空页**；没有 `0.*` 时该页本页图**留空** |
| 与已有数据的关系 | **清空重建**：整本书按这棵目录树重新生成（`logo` 与「窑口图录」条目不动） |
| 上传交互 | 选完目录先弹**识别结果预览**，用户点「开始导入」才上传 |
| 取目录方式 | `<input type="file" webkitdirectory>` |
| 预览图格式 | **按原文件类型**：原 PNG → 存 PNG，其余 → 存 JPEG(q0.85) |
| 页码保护 | 不设硬上限；页数 > 300 时预览里高亮并要**二次确认** |

### Task B1: `SD.Materials` 补两件小事

**Files:**
- Modify: `build/js/03-materials.js`（`importFiles` 里的 sort 约 124-127 行；`upload()` 里的 `toBlob` 约 111 行；返回对象约 186-195 行）
- Test: `build/.verify/probe_mat_format.py`（新建）

**Interfaces:**
- Produces:
  - `SD.Materials.naturalCompare(a, b)` → `number`（`<0` 表示 a 排前面）
  - `upload(file, axis, opts)` 的第三参暂时不用；行为变化见下

#### 背景

`importFiles` 里已经有一句自然排序（`localeCompare(..., {numeric:true})`），
识别器要用**同一处规则**给帧排序 —— 两套规则漂移会让「预览里看到的帧序」和
「实际传上去的顺序」不一致，而 **360 帧序错一格整个旋转就错乱**。

预览图格式必须分：实测书页素材 `2000×2695` 降采样到 960 后，
存 PNG 是 **462 KB/张**（704 张 = **317 MB**，全压在本地服务内存里），
存 JPEG 只要 **59 KB/张**（共 41 MB）。

import subprocess
import sys

CHECK = """async () => {
  var out = {};
  /* --- 1) 排序 --- */
  var nc = SD.Materials.naturalCompare;
  out.hasFn = typeof nc === 'function';
  if (out.hasFn) {
    out.pair2_10 = nc('2.JPG', '10.JPG');        /* 期望 < 0 */
    out.pair10_2 = nc('10.JPG', '2.JPG');        /* 期望 > 0 */
    /* 大小写混用不该影响顺序（实测目录里 0.jpg 与 1.JPG 混用） */
    var arr = ['10.JPG', '2.jpg', '1.JPG'];
    arr.sort(nc);
    out.sorted = arr.join(',');
  }
  /* --- 2) 预览图格式 --- */
  function mkBlob(w, h, mime) {
    var c = document.createElement('canvas');
    c.width = w; c.height = h;
    var g = c.getContext('2d');
    for (var i = 0; i < 40; i++) {
      g.fillStyle = 'hsl(' + (i * 9) + ',70%,50%)';
      g.fillRect((i * 37) % w, (i * 53) % h, 220, 220);
    }
    return new Promise(function (r) { c.toBlob(r, mime, 0.9); });
  }
  async function up(name, mime) {
    var blob = await mkBlob(1600, 1200, mime);
    var f = new File([blob], name, { type: mime });
    var items = await SD.Materials.importFiles([f], 'x', null);
    var it = items[0];
    var r = await fetch(it.url);
    var got = await r.blob();
    return { url: it.url, type: got.type, size: got.size };
  }
  out.png = await up('a.png', 'image/png');
  out.jpg = await up('b.jpg', 'image/jpeg');
  return out;
}"""


def main():

                           stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)

        print('服务没起来：', e)

        return 1
    bad = 0
    try:
        from playwright.sync_api import sync_playwright
        with sync_playwright() as pw:
            b = pw.chromium.launch(channel="chrome")
            page = b.new_page(viewport={"width": 1400, "height": 900})
            page.goto(BASE + '/studio.html', wait_until='load')
            page.wait_for_function('!!window.SD && !!window.SD.Materials', timeout=20000)
            r = page.evaluate(CHECK)
            print('naturalCompare 存在 :', r['hasFn'])
            if not r['hasFn']:
                print('  !! SD.Materials.naturalCompare 还没提出去')
                bad += 1
            else:
                print("  nc('2.JPG','10.JPG') =", r['pair2_10'], '（期望 < 0）')
                print("  nc('10.JPG','2.JPG') =", r['pair10_2'], '（期望 > 0）')
                print('  排序结果 :', r['sorted'], '（期望 1.JPG,2.jpg,10.JPG）')
                if not (r['pair2_10'] < 0 and r['pair10_2'] > 0):
                    print('  !! 不是数字感知排序')
                    bad += 1
                if r['sorted'] != '1.JPG,2.jpg,10.JPG':
                    print('  !! 排序结果不对（大小写混用也不该乱）')
                    bad += 1
            print('PNG 上传后 :', r['png'])
            print('JPEG 上传后:', r['jpg'])
            if 'png' not in (r['png']['type'] or ''):
                print('  !! PNG 原图应当还是 PNG')
                bad += 1
            if 'jpeg' not in (r['jpg']['type'] or ''):

                bad += 1
            if r['jpg']['size'] >= r['png']['size']:

                bad += 1
            b.close()
    finally:
        srv.terminate()
    print('结果：', 'FAIL' if bad else 'OK')
    return 1 if bad else 0


if __name__ == '__main__':

新建 `build/js/09-dirimport.js`：

```js
/* =====================================================================
 * 09-dirimport.js —— 批量导入：目录树识别
 *
 * 纯函数：输入「文件路径表」，输出「这本书长什么样」。
 * 不碰 DOM、不碰 SD.STATE、不发请求 —— 这样可以在探针里直接喂假路径断言
 * （见 build/.verify/probe_dirimport.py）。
 *
 * 认识的目录形态（真实图录就是这么摆的）：
 *   根/封面.jpg          → 封面
 *   根/封底.jpg          → 封底
 *   根/1/0.jpg           → 第 1 页的本页图
 *   根/1/1.JPG 2.JPG …   → 第 1 页的 360 帧（按数字排序）
 * ===================================================================== */
window.SD = window.SD || {};

SD.DirImport = (function () {
  var IMG_RE = /\.(jpe?g|png|webp|gif|bmp|avif|tiff?)$/i;
  var NUM_RE = /^\d+$/;
  var WARN_PAGES = 300;      /* 超过这个页数要在预览里二次确认（不硬拒） */

  function stem(name) { return String(name || '').replace(/\.[^.]+$/, '').trim(); }
  function isImage(name) { return IMG_RE.test(String(name || '')); }
  /* macOS 会往目录里塞 .DS_Store 与 ._xxx 资源叉文件；
     后者扩展名可能是 .jpg，不过滤就会被当成图片混进帧序。 */
  function isJunk(name) { return String(name || '').charAt(0) === '.'; }

  function scan(entries) {
    var list = (entries || []).filter(function (e) { return e && e.path; });
    var warnings = [];
    var system = 0, other = 0;
    var cover = null, back = null;
    var byPage = {};
    var nonNumDirs = {}, nestedDirs = {};
    var dupFrame = 0;

    var root = '';
    list.forEach(function (e) {
      var p = String(e.path).replace(/\\/g, '/');
      var i = p.indexOf('/');
      if (i < 0) return;                          /* 没有目录层，忽略 */
      var seg = p.slice(i + 1).split('/');
      if (!seg.length || !seg[seg.length - 1]) return;
      if (!root) root = p.slice(0, i);
      var name = seg[seg.length - 1];
      if (isJunk(name)) { system += 1; return; }

      if (seg.length === 1) {
        /* 根目录下的文件：只看封面 / 封底 */
        if (!isImage(name)) { other += 1; return; }
        var st = stem(name);
        if (st === '封面') {
          if (!cover) cover = e;
          return;
        }
        if (st === '封底') {
          if (!back) back = e;
          return;
        }
        other += 1;
        return;
      }

      if (seg.length > 2) { nestedDirs[seg[0]] = 1; return; }

      var dir = seg[0];
      if (!NUM_RE.test(dir)) { nonNumDirs[dir] = 1; return; }
      var no = parseInt(dir, 10);
      if (!(no >= 1)) { other += 1; return; }
      if (!isImage(name)) { other += 1; return; }
      var slot = byPage[no] || (byPage[no] = { no: no, pageImg: null, frames: [] });
      if (stem(name) === '0') {
        if (!slot.pageImg) slot.pageImg = e; else other += 1;
      } else {
        var fname = name;
        var dup = slot.frames.some(function (f) { return f.name === fname; });
        if (dup) dupFrame += 1; else slot.frames.push(e);
      }
    });

    /* 帧序：用与上传同一处的比较器，避免两套规则漂移 */
    var nc = (SD.Materials && SD.Materials.naturalCompare) || null;
    var nos = Object.keys(byPage).map(Number).sort(function (a, b) { return a - b; });
    var maxNo = nos.length ? nos[nos.length - 1] : 0;
    var pages = [];
    var images = 0;
    if (cover) images += 1;
    if (back) images += 1;
    for (var n = 1; n <= maxNo; n++) {
      var s = byPage[n] || { no: n, pageImg: null, frames: [] };
      s.frames.sort(function (a, b) {
        return nc ? nc(a.name, b.name)
                  : String(a.name).localeCompare(String(b.name), 'zh-Hans-CN',
                      { numeric: true, sensitivity: 'base' });
      });
      pages.push({ no: n, pageImg: s.pageImg, frames: s.frames });
      if (s.pageImg) images += 1;
      images += s.frames.length;
      if (!s.pageImg) warnings.push({ code: 'page-without-image', text: '第 ' + n + ' 页没有 0.* 本页图' });
      if (!s.frames.length) warnings.push({ code: 'page-without-frames', text: '第 ' + n + ' 页没有 360 素材' });
    }

    if (!cover) warnings.push({ code: 'no-cover', text: '根目录下没找到「封面.xxx」' });
    if (!back) warnings.push({ code: 'no-back', text: '根目录下没找到「封底.xxx」' });
    if (!pages.length) warnings.push({ code: 'no-pages', text: '没有识别到任何数字命名的子目录（内容页）' });
    Object.keys(nonNumDirs).forEach(function (d) {
      warnings.push({ code: 'non-numeric-dir', text: '忽略非数字目录：' + d + '/' });
    });
    Object.keys(nestedDirs).forEach(function (d) {
      warnings.push({ code: 'nested-dir', text: '忽略更深层的目录：' + d + '/…' });
    });
    if (dupFrame) warnings.push({ code: 'duplicate-frame', text: '有 ' + dupFrame + ' 个重名帧被跳过' });
    if (pages.length > WARN_PAGES) {
      warnings.push({ code: 'too-many-pages',
                      text: '识别到 ' + pages.length + ' 页，超过 ' + WARN_PAGES + ' 页，导入前请确认' });
    }
    if (other) warnings.push({ code: 'ignored-files', text: '另有 ' + other + ' 个文件认不出，已跳过' });

    return {
      root: root,
      cover: cover, back: back,
      pages: pages,
      total: { pages: pages.length, images: images },
      skipped: { system: system, other: other },
      warnings: warnings
    };
  }

  return { scan: scan, WARN_PAGES: WARN_PAGES };
})();
```

在 `08-app.js` 里、`showImportPlan` 之后插入：

```js
  /* 把识别结果一条条传上去。全部成功之后才动 STATE.book ——
     中途取消或失败时工作台保持原样，不会出现「清了半本」。 */
  function runBatchImport(plan) {
    var urlOf = '/@upload';
    /* 上传队列：每项是「传一组图，结果放回 plan 的哪个位置」 */
    var jobs = [];
    if (plan.cover) jobs.push({ kind: 'cover', files: [plan.cover.file] });
    if (plan.back) jobs.push({ kind: 'back', files: [plan.back.file] });
    plan.pages.forEach(function (p, i) {
      if (p.pageImg) jobs.push({ kind: 'pageImg', page: i, files: [p.pageImg.file] });
      if (p.frames.length) {
        jobs.push({ kind: 'frames', page: i,
                    files: p.frames.map(function (f) { return f.file; }) });
      }
    });

    var totalImgs = plan.total.images;
    var doneImgs = 0;
    var missing = [];
    var out = { cover: null, back: null, pages: plan.pages.map(function (p) {
      return { url: '', name: '', file: null, items: [] };
    }) };
    var cancelled = false;

    var box = document.createElement('div');
    box.className = 'import-prog';
    box.innerHTML = '<div class="import-prog-bar"><i></i></div>' +
                    '<div class="import-prog-txt"></div>' +
                    '<button class="btn ghost sm" data-stop>取消</button>';
    document.body.appendChild(box);
    var bar = box.querySelector('i');
    var txt = box.querySelector('.import-prog-txt');
    box.querySelector('[data-stop]').addEventListener('click', function () {
      cancelled = true;
      txt.textContent = '正在取消…';
    });
    function setProg(name) {
      var pct = totalImgs ? Math.round(doneImgs / totalImgs * 100) : 100;
      bar.style.width = pct + '%';
      txt.textContent = '正在上传 ' + Math.min(doneImgs + 1, totalImgs) + ' / ' + totalImgs +
                        (name ? ' · ' + name : '');
      status('批量导入中 ' + pct + '%');
    }
    function finish() {
      if (box.parentNode) box.parentNode.removeChild(box);
    }

    var chain = Promise.resolve();
    jobs.forEach(function (job) {
      chain = chain.then(function () {
        if (cancelled) return null;
        setProg(job.files[0] && job.files[0].name);
        return SD.Materials.importFiles(job.files, 'x', function (i, n, nm) {
          /* 这一批内部的进度：doneImgs 已经累加了前面几批 */
          var pct = totalImgs ? Math.round((doneImgs + i) / totalImgs * 100) : 100;
          bar.style.width = pct + '%';
          txt.textContent = '正在上传 ' + (doneImgs + i) + ' / ' + totalImgs + ' · ' + nm;
          status('批量导入中 ' + pct + '%');

          doneImgs += job.files.length;
          if (job.kind === 'cover') out.cover = items[0] || null;
          else if (job.kind === 'back') out.back = items[0] || null;
          else if (job.kind === 'pageImg') out.pages[job.page] = items[0] || out.pages[job.page];
          else if (job.kind === 'frames') out.pages[job.page].items = items || [];
          /* 上传失败的记下来（importFiles 失败时仍 resolve，只是没有 url） */
          (items || []).forEach(function (it) {
            if (!it || !it.url) missing.push((it && it.name) || '（未知文件）');
          });
        });
      });
    });

    return chain.then(function () {
      finish();
      if (cancelled) {
        status('已取消批量导入');
        toast('warn', '已取消', '工作台保持原样，没有改动任何书页');
        return;
      }
      /* ---- 到这里所有图都传完了，才动 state（清空重建） ---- */
      var bk = SD.Book ? SD.Book.book() : (STATE.book = STATE.book || {});
      bk.cover = out.cover ? { url: out.cover.url, name: out.cover.name, file: out.cover.file } : null;
      bk.back = out.back ? { url: out.back.url, name: out.back.name, file: out.back.file } : null;
      bk.pages = out.pages.map(function (p) {
        return { url: p.url || '', name: p.name || '', file: p.file || null, items: p.items || [] };
      });
      bk.active = 0;

      /* 画布比例跟着封面走（和单张上传封面那段一致） */
      if (bk.cover && bk.cover.url) {
        var im = new Image();
        im.onload = function () {
          if (bk.cover && bk.cover.url === out.cover.url) {
            bk.cover.w = im.naturalWidth;
            bk.cover.h = im.naturalHeight;
            bk.w = im.naturalWidth || bk.w;
            bk.h = im.naturalHeight || bk.h;
            SD.Book.render();
            refresh();
            SD.Store.autoSave();
          }
        };
        im.src = bk.cover.url;
      }
      SD.Book.render();
      refresh();
      SD.Store.autoSave();          /* 只在这里存一次 */
      status('批量导入完成');
      toast('ok', '批量导入完成',
        '已导入 ' + plan.total.pages + ' 页 / ' + plan.total.images + ' 张图' +
        (missing.length ? ('（' + missing.length + ' 张失败）') : ''),
        missing.length ? 9000 : 5000);
      if (missing.length) {
        console.warn('[批量导入] 这些文件没传成功：', missing);
      }
    }).catch(function (e) {
      finish();
      status('批量导入失败', 'err');
      toast('err', '批量导入失败', (e && e.message) || '请重试');
    });
  }
```

- [ ] **Step 1: 写端到端探针**

Playwright 的 `set_input_files()` 支持直接传一个**目录**，并自动填好
`webkitRelativePath` —— 天生贴合这个功能。

```python
# -*- coding: utf-8 -*-
"""端到端：真的选一个目录 → 识别 → 导入 → 断言书页被填满、产物引用正确。

自带本地服务；夹具目录现场生成（不需要外部素材）。
用法：python -X utf8 build/.verify/probe_batch_import.py
"""
import os
import shutil
import subprocess
import sys
import time
import urllib.request

try:
    sys.stdout.reconfigure(encoding='utf-8', errors='replace')
except Exception:
    pass

ROOT = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
PY = sys.executable
BASE = 'http://localhost:8788'
FIX = os.path.join(ROOT, 'build', '.verify', 'e2e', 'batch', '青花瓷')

# 3 个页面槽位：1 有本页图+2 帧；2 只有本页图；3 有本页图+1 帧。
# 另外放一个非数字目录和一个系统文件，验证它们被忽略。
LAYOUT = {
    '封面.jpg': None, '封底.jpg': None,
    '.DS_Store': None,
    '1/0.jpg': None, '1/1.jpg': None, '1/2.jpg': None,
    '2/0.jpg': None,
    '3/0.jpg': None, '3/1.jpg': None,
    '备份/readme.txt': None,
}


def make_fixture():
    src = os.path.join(ROOT, 'build', '.verify', 'e2e', 'perf', 'book', 'page-1.jpg')
    if not os.path.exists(src):
        print('!! 缺夹具图，请先跑 make_perf_fixture.py')
        return False
    if os.path.isdir(FIX):
        shutil.rmtree(FIX)
    for rel in LAYOUT:
        p = os.path.join(FIX, *rel.split('/'))
        os.makedirs(os.path.dirname(p), exist_ok=True)
        if rel.endswith('readme.txt'):
            open(p, 'w').write('not an image')
        else:
            shutil.copyfile(src, p)
    return True


def main():
    if not make_fixture():
        return 1
    srv = subprocess.Popen([PY, '-m', 'http.server', '8788', '--directory', ROOT],
                           stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    time.sleep(3)
    try:
        urllib.request.urlopen(BASE + '/studio.html', timeout=5).read(1)
    except Exception as e:
        print('服务没起来：', e)
        srv.terminate()
        return 1
    bad = 0
    try:
        from playwright.sync_api import sync_playwright
        with sync_playwright() as pw:
            b = pw.chromium.launch(channel="chrome")
            page = b.new_page(viewport={"width": 1500, "height": 950})
            errs = []
            page.on('pageerror', lambda e: errs.append(str(e)))
            page.goto(BASE + '/studio.html', wait_until='load')
            page.wait_for_function('!!window.SD && !!window.SD.DirImport', timeout=20000)
            page.wait_for_timeout(800)

            # 点按钮 → 探针替用户「选目录」
            with page.expect_file_chooser() as fc:
                page.click('#btnBatchImport')
            fc.value.set_files(FIX)          # ← 传目录：Playwright 会填好相对路径
            page.wait_for_selector('.modal-mask', timeout=8000)
            plan_txt = page.inner_text('.modal-mask')
            print('识别结果预览：')
            for line in plan_txt.splitlines()[:12]:
                print('   ', line)
            if '识别到 3 页' not in plan_txt:
                print('  !! 预览里应当写「识别到 3 页」')
                bad += 1
            page.click('.modal-mask [data-go]')

            # 等进度条消失 = 导入结束
            page.wait_for_selector('.import-prog', timeout=8000)
            page.wait_for_selector('.import-prog', state='detached', timeout=120000)
            page.wait_for_timeout(1200)

            st = page.evaluate("""() => {
              var bk = window.SD.Book.book();
              return {
                cover: !!(bk.cover && bk.cover.url),
                back: !!(bk.back && bk.back.url),
                pages: bk.pages.length,
                pageImgs: bk.pages.filter(function (p) { return !!p.url; }).length,
                items: bk.pages.map(function (p) { return (p.items || []).filter(function (i) { return !i.off; }).length; }),
                rowCount: document.querySelectorAll('#bookList .lot-row').length
              };
            }""")
            print('导入后 :', st)
            if not st['cover'] or not st['back']:
                print('  !! 封面/封底没有填上')
                bad += 1
            if st['pages'] != 3:
                print('  !! 应当是 3 个内容页，实际 %d（非数字目录/系统文件不该产生页）' % st['pages'])
                bad += 1
            if st['pageImgs'] != 3:
                print('  !! 3 页都该有本页图，实际 %d' % st['pageImgs'])
                bad += 1
            if st['items'] != [2, 0, 1]:
                print('  !! 每页 360 素材数应当是 [2,0,1]，实际 %s' % st['items'])
                bad += 1
            if st['rowCount'] != 5:
                print('  !! 左栏应当是 5 行（封面+3 页+封底），实际 %d' % st['rowCount'])
                bad += 1

            # 产物里的引用也要对：帧序不能乱
            html = page.evaluate("window.SD.Codegen.buildHtml(window.SD.STATE, { mode: 'files' })")
            for must in ['book/cover', 'book/back', 'book/page-1', 'book/page-2', 'book/page-3',
                         'book/page-1/1.jpg', 'book/page-1/2.jpg', 'book/page-3/1.jpg']:
                if must not in html:
                    print('  !! 产物里缺少引用：', must)
                    bad += 1
            if 'page-1/2.jpg' in html and html.index('page-1/1.jpg') > html.index('page-1/2.jpg'):
                print('  !! 第 1 页的帧序反了')
                bad += 1
            if errs:
                print('  !! 页面报错：', errs[:3])
                bad += 1
            b.close()
    finally:
        srv.terminate()
    print('结果：', 'FAIL' if bad else 'OK')
    return 1 if bad else 0


if __name__ == '__main__':
    sys.exit(main())
```
