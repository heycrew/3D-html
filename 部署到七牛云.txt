========================================
   把导出的图录部署到七牛云（Kodo）
========================================

一、先理清楚：什么该传，什么不该传
----------------------------------
导出目录长这样：

    index.html          页面本体（唯一入口）
    images/             拍品 360 素材（博古架/单品模式用）
    book/               书页图 + 每页的 360 素材（翻书图录用）
    lib/                整个文件夹都要传，里面有三样：
        └ 360-view.min.js        360 查看器库（少了它画面出不来）
        └ vysmo-flipbook.min.js  翻页库（少了它书页翻不动）
        └ sound/book-voice.mp3   翻页音效（开了「翻页音效」就得有它，少了没声音）
    serve.ps1           本机预览用的服务器  ← 不要传
    启动.bat            本机预览用的启动脚本 ← 不要传
    使用说明.txt        给本地看的说明       ← 不要传

上七牛只需要传这四样：index.html、images/、book/、lib/
（serve.ps1 与 启动.bat 是本地双击预览用的，跟线上无关）

★ lib/ 是「整个文件夹」一起传，别只挑 360-view.min.js。
  它里面还有个 sound/ 子目录，漏了音效文件线上就没有翻页声。

为什么不能在本地直接双击 index.html 打开？
  360 查看器对图片强制要求 crossOrigin="anonymous"，
  file:// 协议下图片会被判为跨域而拒绝绘制。必须走 http(s)。
  七牛云正好提供 http(s)，所以部署上去就正常了。


二、七牛云控制台操作（推荐，最省事）
----------------------------------
1. 登录七牛云 → 对象存储 Kodo → 新建空间
     空间名称：随意（如 auction-catalog）
     存储区域：挑离你近的
     访问控制：必须选【公开】 ← 私有空间线上打不开

2. 进入这个空间 → 「内容管理」→ 上传文件
     把 index.html 拖进去
     再把 images / book / lib 三个文件夹整体拖进去
     ★ 关键：必须保持原来的目录层级，不要把它们压平

3. 找到空间的【域名】——控制台里叫「外链域名」
     形如：xxxxx.clouddn.com（七牛给的测试域名）
     或你自己绑定的域名（如 img.你的域名.com）

4. 浏览器打开：
     http://<你的域名>/index.html

     如果嫌要输 index.html 麻烦，可以开静态网站托管：
       空间设置 → 静态网站托管 → 默认首页填 index.html
     之后直接访问 http://<你的域名>/ 即可。


三、如果想用命令行批量上传（文件多时）
----------------------------------
七牛官方工具 qshell：https://github.com/qiniu/qshell

  # 1) 配置账号（AK/SK 在控制台「密钥管理」里）
  qshell account <AccessKey> <SecretKey> 你的名字

  # 2) 批量上传：在导出目录下执行
  qshell qupload2 \
    --src-dir=. \
    --bucket=auction-catalog \
    --overwrite=true \
    --skip-suffixes=ps1,bat,txt

  # 说明：--skip-suffixes 把 serve.ps1 / 启动.bat / 说明 排除掉。
  #       mp3 不在跳过名单里，所以 lib/sound/book-voice.mp3（翻页音效）会一起传上去。


四、上线后改内容怎么办（很重要）
----------------------------------
七牛是 CDN 加速的，文件传上去以后会被各地节点缓存。
如果你更新了 index.html 或换了图片，访问时可能还是旧的。

  控制台 → CDN → 刷新预取 → 提交刷新
     URL 刷新：填 http://<域名>/index.html
     目录刷新：填 http://<域名>/         （整个目录都刷）

命令行方式：
  qshell cdnrefresh -i refresh.txt      # refresh.txt 里每行一个 URL

★ 这一条务必记住 —— 否则会出现「明明重新传了，打开还是老样子」。


五、几个容易踩的点
----------------------------------
1. 空间访问控制选了「私有」
   → 线上打开是 403 或者白屏。必须是【公开】。

2. 上传时把 images / book 压平了
   → 页面里的相对路径找不到图，出来是空白书页。
   保持目录结构：images/lot-1/xxx.jpg、book/page-1/xxx.jpg

3. 用了七牛的测试域名
   → 测试域名有有效期（一般 30 天），过期就访问不了。
   正式用请绑定自己的域名。

4. 国内想用自定义域名 + HTTPS
   → 域名需要完成备案，然后在 CDN 里上传 SSL 证书。

5. 图片太大
   → 打开工作台的「体检」看看有没有单张超 3MB 的，
   建议压到 500KB 以内，线上加载会快很多。

6. lib/ 只挑了 360-view.min.js 传
   → 少了 vysmo-flipbook.min.js，翻书页点不动、也不翻页；
   少了 sound/book-voice.mp3，开了「翻页音效」同样没声音。
   lib/ 连同它里面的 sound/ 子目录一起传，就不会漏。


六、一条命令验证部署是否成功
----------------------------------
在任意机器上执行（把域名换成你自己的）：

  curl -I http://<你的域名>/index.html
  curl -I http://<你的域名>/lib/360-view.min.js
  curl -o /dev/null -s -w "%{http_code}\n" http://<你的域名>/images/lot-1/第1张图.jpg

三个都返回 200，就说明文件齐了、层级也对。
若有 404，多半是目录层级被压平，或者文件没传全。
