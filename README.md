# 360° 全景展示工作台

**[中文](README.md) | [English](README.en.md)**

一个纯前端的 **360° 全景 / 翻书图录** 制作工作台：在浏览器里导入素材、右侧调参数、一键导出一个可独立部署的静态页面（`index.html` + 图片目录 + `lib/`）。

面向两类场景：**一件藏品的 360° 旋转展示**，和**一本可以 3D 翻页的图录**。藏品图录、产品画册、展厅导览之类的需求可以直接套用。

## 特性

- **纯前端** —— 产物只有 HTML / CSS / JS / 图片，不需要后端、数据库，也不需要构建步骤
- **零外部依赖** —— 导出的页面只依赖两个第三方库（均为 MIT），不联网也能跑；需要时可选接 Cloudimage CDN 做图片转码
- **所见即所得** —— 工作台右侧改参数，预览区立即生效；导出前就能看到最终效果
- **3D 旋转（360° 全景）** —— 水平环绕 + 俯仰 + 二维网格三轴，支持帧插值平滑、拖动惯性、双指缩放、全屏、热点标记、自动旋转
- **3D 翻页（翻书图录）** —— WebGL 卷曲翻页，支持拖拽掀页、循环翻页、页码导航、360 素材缩略图、双击放大、自动翻页、翻页音效
- **绿色版桌面应用** —— Windows 10 / 11 双击即用，免安装、不需要 Node / Python / IIS，也不需要管理员权限
- **移动端可用** —— 导出的页面在手机浏览器与微信内置浏览器里都能用（含针对内核差异的引擎自动降级）

## 快速开始

### 方式一：绿色版桌面应用（最省事）

把 `desktop/dist/win-unpacked/` 整个文件夹拷到目标电脑，双击里面的 `360全景展示工作台.exe`。
应用会自己在 `127.0.0.1` 起一个内置服务并打开窗口，用完直接关窗口即可。

> 打包产物约 200MB（自带 Chromium），这是「在任何 Win10 / Win11 上都能跑」的代价。

### 方式二：本地起服务（不用打包）

1. 双击 `启动工作台.bat`
2. 浏览器会自动打开工作台（形如 `http://localhost:8788/studio.html`）
3. 导入素材 → 右侧调参数 → 点右上「导出 HTML」选一个空文件夹

> **为什么不能直接双击 `studio.html`？**
> Cloudimage 360 View 会给每张图片设置 `crossOrigin="anonymous"`，浏览器在 `file://` 协议下会拦掉这些请求，预览会一片空白。启动器用 Windows 自带的 PowerShell 起一个本地服务，零安装、无需管理员权限。

### 方式三：从源码构建

```bash
python3 build/build.py          # 由 build/js/*.js 生成 studio.html（并做产物语法自检）
```

构建只依赖 Python 3 标准库，不需要 npm。

## 使用流程

1. **导入素材** —— 左侧「图片源」选区选目录，或把图片直接拖进来；工作台会按文件名序号自动排序
2. **调参数** —— 右侧参数面板分组展示，改完即时预览
3. **导出** —— 点右上「导出 HTML」，选一个空文件夹，得到可独立部署的静态产物

### 素材建议

- 支持任意帧数，最少的「前后左右上下」6 张也能用
- 帧数少于 8 时旋转会略显跳跃：建议前 4 张做水平环绕，「上 / 下」两张填进参数的「垂直」组，用上下拖动看俯仰
- 一圈 24 张以上观感最顺滑
- 文件名带序号（如 `1.jpg`、`p02.jpg`）会自动按顺序排好

## 功能明细

### 一、360° 全景（3D 旋转）

**图片源**

| 参数 | 说明 |
| --- | --- |
| 图片目录 / 文件名模板（水平） | 图片位置与命名规则，`{index}` 替换为序号 |
| 水平帧数 | 一圈拍了多少张（1–240） |
| 序号补零位数 | `3` 表示 `001`、`002`… |
| 帧插值平滑 | 在相邻帧之间插过渡帧，`0` 关闭。**拍照张数少时调到 2~3 会顺滑很多** |
| 垂直帧数 / 文件名模板（垂直） | 俯仰视角那一组；`0` = 不启用垂直轴 |
| 网格文件名模板 | 二维网格素材，含 `{indexX}` 与 `{indexY}` |
| 水平 / 垂直 / 网格图片列表 | 文件名不规则时改用列表，每行一个 URL；填了就忽略目录 + 模板 |

**旋转行为**：自动旋转开关、自动旋转方式（水平环绕 / 垂直环绕 / 逐行扫描 / 逐列扫描）、反向、只播一遍、旋转间隔、拖动惯性。

**交互控制**：鼠标拖动、触摸滑动、拖动灵敏度、方向反向、方向键控制、到边界停止（可对水平 / 垂直分别设三态）、双指缩放。

**外观与控件**：容器宽高比、内置主题（浅色 / 深色）、全屏按钮、最大放大倍数、缩放步进、缩放按钮组及其位置、滚轮缩放提示、首次交互提示、初始 360° 图标、底部进度环及其偏移、点击后才加载、懒加载。

**热点**：触发方式（悬停 / 点击）、点时间轴显示弹窗、标记样式、品牌色。

### 二、翻书图录（3D 翻页）

一本书 = **封面 + N 张内容页 + 封底**，统一尺寸显示。每个内容页还可以自带一组 360 素材，点击页面即弹出查看。

| 参数 | 说明 |
| --- | --- |
| 书宽 / 书高 / 尺寸适配 | 跟随封面图时，画布比例自动等于封面图，不留空白 |
| 翻页时长 | 一次翻页动画的时长 |
| 卷边斜向 | 卷边斜着推进的程度，`0` = 整条竖边平移 |
| 纸背颜色 | 翻动页背面的颜色 |
| 拖拽翻页 / 拖拽提交阈值 | 手指或鼠标能把纸页掀起来跟手；拖过多少比例松手才翻过去，不到就回弹 |
| 循环翻页 | 翻到最后一页再往后翻回到第 1 页 |
| 预载页数 | 当前页前后各预载几页。**它直接决定纹理显存**，一张 1500×2000 的图约占 12MB，移动 GPU 上默认值调太大会崩（症状是书页空白、怎么翻都不动） |
| 首次加载提示 / 加载文案 / 显示加载进度 / 加载页说明文字 | 素材还没就位时先显示一层提示，避免白屏 |
| 桌面背景 | 书页四周的留白底色 |
| 显示页码导航 | 底部那条：左边目录按钮、中间页码、右边「自动翻页」；点页码会展开拖动进度条 |
| 目录按钮名 | 底部左侧按钮与图墙标题的文字。图墙内容由左侧「目录」里配的条目决定（页码 + 标题 + 自定义图） |
| 360 素材缩略图 | 导航条上方那条：本页有几张 360 素材就画几张缩略图，点第 N 张就从第 N 帧开始看；没有素材时整条自动隐藏 |
| 双击放大查看 | 双击内容页进入全屏大图：双指 / 滚轮缩放、拖动平移、双击复位 |
| 自动翻页间隔 | 点「自动翻页」后每隔多久翻一页，翻到最后一页自动停下 |
| 翻页音效 / 音效来源 / 自定义路径 / 音量 | 用 `<audio>` 播放，手机的静音开关下也能听见。内置音效文件不随仓库分发，需自行放到 `lib/sound/book-voice.mp3` |
| 360 帧插值平滑 | 弹层里 360 的插值（同「图片源」里的那一项） |
| 分享按钮 / 分享标题 / 站点地址 / 分享文案 | 手机调系统分享面板，电脑复制链接；微信里提示「点右上角 → 转发给朋友」 |

### 三、导出产物

导出目录结构：

```
index.html            页面本体（唯一入口）
book/                 书页图 + 每页的 360 素材 + 目录自定义图
  ├ cover.jpg / back.jpg / page-1.jpg …
  ├ page-1/ page-2/ … 某页自带的一组 360 素材
  └ catalog/          目录里配的「自定义图」（配了才有）
lib/                  整个文件夹都要一起部署
  ├ 360-view.min.js       360 查看器
  ├ vysmo-flipbook.min.js 翻页库
  └ sound/book-voice.mp3  翻页音效（需自备）
serve.ps1             本机预览用的服务器（不要上传）
启动.bat               本机预览用的启动脚本（不要上传）
```

上线时只需要传 **`index.html` + `book/` + `lib/`** 三样，并保持目录层级不变（压平会导致图片找不到、页面空白）。

### 四、工作台自身

- 左栏纸张列表：新增 / 删除 / 上下移动页面，每页可挂一组 360 素材
- 「目录」条目管理：页码 + 标题 + 自定义图
- 工程导入 / 导出（配置 JSON），素材存在浏览器本地库里
- 图片体检：找出体积过大的素材（建议单张压到 500KB 以内，线上加载会快很多）

## 技术架构

### 产物端翻页引擎：按平台分流

产物页的翻页由 `12-bookpage.js` 承担，引擎选择遵循「能用 WebGL 就用 WebGL，用不了就退回 canvas」：

| 平台 | 引擎 |
| --- | --- |
| iOS / PC | `webgl2OK()` 能力探测通过则用 WebGL 卷曲（`@vysmo/flipbook`），否则 canvas |
| 安卓 / 鸿蒙等移动端 | 直接使用自研 canvas 2D 卷曲引擎 |

分流的原因：部分移动端内核在页面静止时**不产生渲染帧**，`requestAnimationFrame` 几乎停摆，而 WebGL 引擎的渲染完全依赖 rAF，会出现「打开一片空白、手指一碰才出现」。canvas 引擎的重绘由 `Image.onload` 事件驱动（另有轮询与创建时的同步绘制兜底），不依赖 rAF，因此在移动端更稳。

引擎选择可被 URL 参数覆盖，便于现场排查：`?engine=webgl` 强制 WebGL、`?engine=css` 强制 canvas。同一个页面追加 `?diag` 可以打开诊断浮层，显示引擎、渲染器、版本、页面尺寸、加载与绘制状态等。

### 本地服务的端点契约

命令行版（`serve.ps1`）与桌面版（`desktop/main.js`）实现同一套契约，工作台靠它完成素材导入：

| 端点 | 用途 |
| --- | --- |
| `GET /@ping` | 探测本地服务是否可用（也用于重启后重新导入素材） |
| `POST /@upload` | 导入素材：body 是图片，文件名走 `x-file-name` 头，返回 `{url,size}` |
| `GET /@mat/<seq>/<名字>` | 按上面返回的 URL 取素材（360 查看器只吃真实 URL，不吃 File / Blob） |
| `DELETE /@mat` | 清空素材 |

少任何一个，工作台都会判定「预览不可用」并拒绝导入素材。

## 常见问题

**打开导出页面是空白**
多半是部署时把目录压平了。需要保持 `book/`、`lib/` 的层级；`lib/` 必须整份上传（漏了 `vysmo-flipbook.min.js` 书页翻不动）。音效文件不随仓库分发，需自行放入 `lib/sound/`。

**本地直接双击 `index.html` 打不开**
`file://` 协议下 360 查看器请求的图片会被判为跨域而拒绝绘制，必须走 HTTP(S)。导出目录里附带了 `启动.bat` 用于本地预览。

**手机上打开没有封面 / 要滑一下才出现**
已针对移动端内核做了引擎分流与加载时序处理：加载遮罩会等当前页真正可画了才撤掉。若仍遇到，请用 `?diag` 打开诊断浮层并把那一屏信息保留下来。

**改了参数但线上还是老样子**
部署到 CDN 后需要刷新缓存（控制台「刷新预取」，或等缓存过期）。
